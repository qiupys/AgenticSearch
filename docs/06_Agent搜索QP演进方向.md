# QP 作为 Agent 搜索引擎入口：演进方向规划

> 定位：QP 不只是「分类器」，而是 agent 搜索引擎的**查询理解与任务规划入口**——
> 把自然语言 query 翻译成结构化检索计划（搜什么、去哪搜、怎么排序、要不要追问）。
> 本文按优先级列出可建设方向，对齐试用期考核三阶段节奏。

## 1. 近期（阶段一内可做，纯规则/词典，收益直接）

| 方向 | 说明 | 现状 |
|---|---|---|
| **实体链接到证券主数据** | 「茅台」「茅台股份」「600519」「MOUTAI」→ 同一标的；含别名/拼音/ticker/曾用名映射 | 词典种子已就位，缺主数据接入 |
| **结构化路由** | 行情/财务/基金类意图（INFO-01~06）不该走内容检索，应路由到行情 API/财报 DB；QP 输出 `route: structured \| content \| both` | recall_linkage 已有 weight=0.3 的雏形 |
| **多时间表达融合** | 「最新\|2026年8月」双锚点 → 召回时间窗计算规则（锚点=最新 + 区间约束 = 该区间的增量信息） | 已支持多 raw，窗口融合规则待写 |
| **可回答性预判（answerability）** | 「002415 的下季度订单」——数据源没有的，提前告知而非空召回；输出 `answerable + 缺口说明` | 新增，规则版可先做 |
| **Query 改写建议** | 检索式 query 补全时间窗/去歧义（「白银 最新」→「白银 价格 最新」），反哺上游 agent | 体系内已有位置（QP 职责含改写/标准化） |

## 2. 中期（阶段二，随 0.6B/teacher 数据建设）

| 方向 | 说明 |
|---|---|
| **会话上下文 QP（多轮）** | agent 场景 query 带上下文：「它呢？」「那营收呢？」——需要指代消解 + 上一轮意图/实体继承；QP 输入应支持 `query + context` 双字段，模型侧做 context fusion |
| **意图 → 工具调用计划** | 复合意图（如「查公告并对比业绩」）拆解为 agent 工具序列：`[search(公告), fetch(财报), compare]`——QP 输出从「标签」升级为「计划」，这是 QP 对 agent 的核心增量价值 |
| **参数槽位补全与追问** | TRADE/SELECT 域必填槽位缺失时生成追问（「预算多少？风险偏好？」），替代盲目检索；对应 Tier2 的「兜底+推荐追问」路径 |
| **embedding 语义通道** | 本地内容库 TF-IDF 占位 → 金融领域 embedding（或 teacher 蒸馏的小向量模型），双路融合升级为 BM25 + ANN |
| **情绪/立场细粒度** | 内容治理的情绪粗标 → 多空立场+强度+论点抽取（服务 PREDICT 域「多空并呈」约束） |
| **标注平台化** | teacher 标注 + 人工抽检 + badcase 回流工作台（Web 界面），支撑月度迭代闭环 |

## 3. 长期（阶段三及以后，面向线上价值）

| 方向 | 说明 |
|---|---|
| **端到端 A/B 价值验证** | QP 升级 → 召回相关性/Top 结果质量/AI 答案质量的因果链度量（人工评测集 + 线上埋点） |
| **个性化与适当性** | 用户风险等级/持仓上下文进入 QP（TRADE-03/04 域激活），搜索结果按适当性过滤 |
| **多语言对齐** | 英文数据对齐计划：海外基线金标 + 英文 teacher 造数 + mBERT/多语 0.6B，中英同模型 |
| **语义漂移监控** | 升级率/分布/混淆矩阵月度对比，触发体系修订（对照 42 类重聚类） |
| **成本工程** | 缓存命中率（已实现 LRU）→ 语义缓存（相似 query 复用）→ Tier2 大模型 API 的成本配额管理 |

## 4. 优先级建议（数据驱动）

1. **先做实体链接 + 结构化路由**：基线报告显示「数据查询」类占 34%，QP 输出 route 字段直接决定这 1/3 流量的通路，改动小、收益最大
2. **可回答性预判**：直接减少「答非所问」类 badcase（基线报告相关性问题 87/160 次的主因之一）
3. **会话上下文 QP**：agent 场景的必备项，但依赖上游 agent 的上下文传递协议，先定义接口
4. **意图→工具计划**：等 0.6B 三头稳定后做，是多意图多标签的 natural extension

## 5. 已就位的基础设施（本仓库）

- 统一 QP 输出 schema（intents/slots/entities/time/recall）——上述所有方向的**扩展点都在 schema 内**，不动接口
- 三级级联 + 服务 + 缓存 + 监控埋点
- 评测体系（合成集/基线金标/切片）+ Web 评测工作台（批量评测页面）
- 本地内容库（BM25+向量融合、意图驱动召回）——端到端检索实验的沙盒
- jieba 金融词典 / NER 词库 —— 实体链接的词料底座
