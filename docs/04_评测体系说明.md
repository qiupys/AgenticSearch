# 评测体系说明

> 评测代码：`evaluation/metrics.py`；Runner：`scripts/run_eval.py`；报告：`data/eval/report/`

## 1. 指标口径（与业务目标一一对应）

| 指标 | 口径 | 业务目标 |
|---|---|---|
| **统计层面准确率** | 产品 16 类口径：预测 L2 命中 `acceptable_l2` 任一即对（configs/category_mapping.json） | ≥85% |
| **排序层面准确率** | L1 域口径：召回 channel 由 L1 驱动，命中 `acceptable_l1` 任一即对 | ≥95% |
| **L1/L2 top1** | 统一体系严格命中（gold_l2 精确比对） | 体系目标 L1≥96% / L2≥88%（级联加权） |
| **L2 top3** | 多标签场景的宽容指标 | — |
| **micro/macro F1** | 42 类逐类 P/R/F1 汇总 | 关注长尾类目 |
| **标的/时间 F1** | NER 实体级 exact match，STOCK+STOCK_CODE+TIME 合并 | ≥99% |
| **Tier 流量分布 / 升级率** | 级联分层统计 | 升级率 ≤7%，突变告警 |
| **时延** | P50/P90/P99（端到端） | P99<50ms（GPU INT8 生产口径） |

**设计说明**：排序层面用 L1 口径的理由——召回 channel 策略匹配（联动矩阵）按意图组/域配置，L1 错误直接导致 channel 错配；统计层面用产品 16 类口径，与产品评测报告对齐，保证双向可比。

## 2. 评测集构成

| 评测集 | 规模 | 金标来源 | 用途 |
|---|---|---|---|
| **合成金标集** `data/eval/synth_gold.jsonl` | 572 条，42 类全覆盖，中英双语 | 模板构造即金标 | 42 类覆盖性验证、回归防护、切片分析 |
| **基线金标集** `data/eval/baseline_gold.jsonl` | 160 条（国内 80 / 海外 80），产品 16 类 | 两份评测报告人工标注 | 真实分布水平度量、业务目标对齐 |
| **银标注留出集** `data/silver/` 抽样 | 5% | 规则弱标注 | 模型拟合监控（不做绝对水平结论） |
| **人工标注集（阶段一交付）** | 目标 1000+ 条 | 人工双标 + 仲裁 | 标准评测集终版、teacher 考试 |

**诚实性说明（写入每份报告）**：
- 合成集与规则共享部分词面模式，其指标反映体系覆盖性与回归基线，不等于线上绝对水平；
- 真实分布绝对水平以 160 条基线金标 + 人工标注集为准；
- 银标注训练 + 银标注评测存在循环性，一律不作为对外结论。

## 3. 分维度切片

语言（zh/en）· 长度桶（<10/10–19/20–29/30+）· 含代码/无代码 · 含时间词/无 · 各意图域 —— 防止「只优化总平均指标造成关键场景退化」（考核硬性要求）。

## 4. 评测流程

```bash
python scripts/ingest_data.py        # 数据接入（query + 基线金标）
python scripts/build_silver.py       # 10万 query 银标注
python scripts/train_lightweight.py  # 训练 Tier1 轻量模型（当前实现）
python scripts/build_evalset.py      # 生成合成评测集
python scripts/run_eval.py           # 全量评测 -> data/eval/report/
```

报告输出 `evaluation_report.md/.json`，包含：合成集指标 + 混淆对 + 切片、基线集统计/排序口径达标情况、NER 实体指标、时延、结论与差距。每次模型迭代必须附上一版报告归档（模型版本 ↔ 报告版本对齐）。
