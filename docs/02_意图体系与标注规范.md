# 意图体系与标注规范（8 域 × 42 二级 + 7 槽位）

> 配套机器可读配置：`configs/intent_taxonomy.json`（体系）· `configs/category_mapping.json`（产品 16 类映射）· `configs/rule_patterns.yaml`（Tier0 模式库）

## 1. 体系总览

| 域 | 二级意图 | 说明 |
|---|---|---|
| **INFO 信息获取** | 01 行情价格 / 02 板块指数行情 / 03 资金筹码 / 04 基本面数据 / 05 基金ETF / 06 技术形态指标 / 07 资讯与公告（含进展跟踪）/ 08 研报与观点（含董秘问答·社媒大V·电话会议）/ 09 多媒体与文献（含法律） | 「查X」统一为「X检索」；要数值、要事实 |
| **ANALYZE 分析研判** | 01 基本面与业绩 / 02 技术面 / 03 资金面 / 04 情绪与风格 / 05 对比 / 06 事件解读（含影响与溯因）/ 07 行业与宏观研判 | 要原因、要评价、要判断 |
| **PREDICT 预测推演** | 01 水平与幅度 / 02 方向与趋势 / 03 相对比较与排名 / 04 状态与等级 / 05 事件结果与时间 / 06 影响传导与路径 | 未发生的事 |
| **SELECT 选标的与机会** | 01 简单条件筛选 / 02 复杂条件推理筛选 / 03 主题与事件驱动选标的 / 04 标的推荐 | 落点是「一批标的」 |
| **QUANT 量化计算与回测** | 01 指标与估值计算 / 02 组合与财务推演 / 03 策略回测 / 04 套利对冲与交易成本 | 要计算过程或统计结果 |
| **TRADE 交易与账户** | 01 买卖点位 / 02 仓位与风控 / 03 投资适当性 / 04 账户诊断与配置（搜索场景挂起） | 建议与个人账户 |
| **SERVICE 知识与服务** | 01 投教科普与技巧 / 02 平台客服问答 / 03 合规与免责 | 学习与功能问答 |
| **SYSTEM 交互与内容** | 01 多模态问答 / 02 内容生成 / 03 任务与跟踪 / 04 交互指令 / 05 通用闲聊与兜底（兼低置信兜底路由） | 指令与非检索请求 |

## 2. 正交槽位（不进分类树，全部为输出字段）

| 槽位 | 取值 | 说明 |
|---|---|---|
| object_type | 个股 / 板块指数 / 基金ETF / 行业 / 宏观 / 无特定对象 | 由 NER 实体 + 关键词驱动；直接决定召回行业过滤 |
| time_anchor | 最新 / 历史时点 / 区间 / 未来 / 无 | 66.3% query 带时间锚点 |
| composite | 单意图 / 复合 | 复合允许 1–3 个意图标签，占 10–15% |
| complexity | 简单 / 复杂 | 仅 SELECT 域 |
| modality | 文本 / 图片 / 文档 / 网页 | 多模态请求 |
| output_form | 文本 / 图表 / 文件 / 代码 | 内容生成类 |
| trigger | 即时 / 定时 / 事件触发 | 任务跟踪类 |

## 3. P0/P1 易混对判别规则（hard negative 优先级）

| 优先级 | 易混对 | 判别规则 |
|---|---|---|
| P0 | SELECT-01/02 筛选 vs SELECT-04 推荐 | 有明确条件/范围=筛选；无条件求「值得买」=推荐 |
| P0 | ANALYZE-06 事件解读 vs SELECT-03 事件驱动选标的 | 落点「影响/怎么看/原因」=解读；「哪些标的受益」=选标的 |
| P0 | INFO-04 财报查询 vs ANALYZE-01 业绩分析 | 要数值=查询；要原因/评价=分析 |
| P0 | INFO-06 技术指标 vs SERVICE-01 投教 | 「X是什么意思」科普问法=投教；「X 当前数值/形态」=查询 |
| P1 | INFO-07 进展检索 vs PREDICT-05 事件结果预测 | 已发生事实=检索；未发生=预测 |
| P1 | INFO-04 评级预期 vs PREDICT-01 水平预测 | 机构已发布预期=查询；用户推演=预测 |
| P1 | INFO-03 vs ANALYZE-03；INFO-07 vs ANALYZE-07 | 同「数值 vs 分析」「事实 vs 判断」判别式 |

> 实测样例：「KDJ是什么意思」→ SERVICE-01（科普问法优先于类目词命中）；「鼎龙股份 最新财报 营收」→ INFO-04；「鼎龙股份 最新财报 分析」→ ANALYZE-01。

## 4. 产品 16 类 ↔ 体系映射（评测口径）

映射表见 `configs/category_mapping.json`。要点：

- 查新闻/查公告 → INFO-07；查研报/大V/电话会议/投资者互动 → INFO-08；查书籍-法律 → INFO-09
- 数据查询 → INFO-01~06 任一可接受（primary INFO-04）；诊断分析 → ANALYZE 全域可接受
- **事实探究核验/事件关联核实**在 42 类中无专属落点：映射取 INFO-04/07/08 并集（评测口径）；**体系修订建议**：增补『事实核验』二级（流量来自基线评测 10/160，且属高价值场景）
- 标的推荐 → SELECT-04；机会挖掘 → SELECT-03/01/02；确定性标的筛选 → SELECT-01/02/03

## 5. 标注输出规范（LLM teacher 标注用）

```json
{
  "intents": [{"domain": "INFO", "intent": "INFO-07", "confidence_signals": "..."}],
  "slots": {"object_type": "个股", "time_anchor": "最新", "composite": "单意图"},
  "rationale": "≤30字，须引用第3节判别规则编号",
  "review": "self-check"
}
```

- 不用 42 类 hard label 单选；多标签（复合样本 1–3 个）
- rationale 引用规则编号，机器可验证
- 置信度**不用 LLM 自报**（系统性过自信），改用：分层选择题 / pairwise 判易混对 / self-consistency 分歧率 / rationale 代理
- teacher 上线前用 500 条人工验证集考试，≥95% 才放量
