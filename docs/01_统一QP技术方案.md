## 1. 背景与目标

### 1.1 业务目标（QP大模型需求文档）

| 层面 | 目标 |
|---|---|
| 统计层面 | 问句意图分类准确率 **≥85%**（产品 16 类口径，用于流量分布统计） |
| 排序效果层面 | 问句意图分类准确率 **≥95%**（L1 域口径，驱动召回 channel 策略匹配） |
| 标的/时间识别 | 准确率 **≥99%**（当前存在少量 badcase） |

### 1.2 现状与基线（两份评测报告 20260821）

- **国内（vs 火山）**：80 条 query、16 类需求。自有胜率 20%、可接受率 30%（火山 65%/75%）。问题归因：相关性 38、时效性 17、多样性 6、权威性 3。
- **海外（vs Google）**：80 条英文 query。自有胜率 30%、可接受率 35%。问题归因：相关性 49、时效性 1、多样性 9、权威性 6。
- **QP 侧结论**：相关性问题是最大短板（87/160 次），其直接上游即 Query 理解——意图识别错误/缺失 → 召回 channel 错配 → 答非所问。QP 升级是拉动相关性与时效性的第一杠杆。

### 1.3 Query 分布现状（10 万条规则标注，覆盖率 89%）

- 头部化：数据查询 ~34% + 资讯/公告检索 ~24% + 事件解读/分析 ~20% ≈ 80%
- 时间敏感：66.3% 带时间锚点；19.1% 含 6 位证券代码 → 实体链接是召回前提
- 形态：「标的/板块 + 时间 + 情报需求点」检索式多关键词并列，非对话式提问
- 体系缺口：行业/宏观研判（~4.2%）在原体系无落点；预测/推荐/回测等类目长尾但高价值

## 2. 总体架构

```
Query（上游 agent 改写后）
   │
   ├─ ① 归一化 + 缓存（query 归一化 LRU，预期命中率 15–25%）
   │
   ├─ ② 三级级联意图识别（8域×42二级 + 多标签 + 置信度）
   │      Tier0 规则快通道 ~65% 流量，<1ms
   │      Tier1 0.6B 判别式三头 ~28%，INT8 <10ms（max-p≥0.75 接受）
   │      Tier2 升级路径 ~7%（大模型 API 异步补算 / 兜底+追问 / SYS-05）
   │
   ├─ ③ NER 实体/时间识别（7 类：STOCK/STOCK_CODE/INDEX/FUND/INDUSTRY/MACRO/TIME）
   │      词典+规则 与 BiLSTM-CRF 模型级联（对标 99%）
   │
   ├─ ④ 正交槽位推断（object_type / time_anchor / composite / ...，不进分类树）
   │
   └─ ⑤ 意图→召回翻译层（情绪策略 / 行业过滤 / 内容类型偏好 / 时间窗，配置表驱动）
          → 输出统一 QP 结构，供召回、排序与产品统计消费
```

**设计原则**

1. **统一而非分散**：中英文共用一套体系、一套数据 schema、一套评测；模型层直接双语（多语骨干 + 字符级特征），英文数据对齐按 160 条基线金标 + 海外合成数据逐步补齐。
2. **级联而非单模型**：0.6B 只做级联一环；系统级指标由「规则 + 校准门限 + 升级」三段拼接达成，在线零 LLM 强依赖。
3. **配置驱动**：意图体系、规则模式库、召回联动矩阵全部配置化（configs/），迭代不改代码。
4. **多标签而非互斥**：复合意图（10–15%）降为多标签输出，禁用 argmax 域内 mask。

## 3. 模型方案（概述，详见 docs/03）

### 3.1 0.6B 判别式三头（在线主力）

- **骨干**：Qwen2.5-0.5B（可升档 1.5B，同架构直换），取最后一层池化向量
- **三头**：L1(8 类 CE，权重 0.3) + L2(42 类 BCE 多标签，权重 1.0) + 槽位头(BCE，权重 0.2)
- **解码**：软解码 score = p_L1(域) × p_L2(类)，top-k 跨域；禁用域内 mask
- **训练**：LLM teacher 结构化标注（离线）→ 软分布蒸馏(KL, T=2~4) + 易混对 SupCon + focal loss 类目均衡 + 槽位重组增强，总数据 3–4 万条
- **校准**：验证集温度缩放 + 按域分组校准，上线前 ECE<0.05
- **部署**：ONNX Runtime/TensorRT INT8（~0.7GB），单次前向无自回归，P99<50ms

### 3.2 NER 序列标注（实体/时间）

- **数据**：规则弱标注 BIO（本仓库已产出 2 万条 / 3.5 万实体）→ 人工/LLM teacher 清洗 → 服务器训练
- **模型**：字符级 BiLSTM-CRF（起点）→ 多语 BERT-CRF（对齐双语要求）
- **级联**：词典/规则（高精度）与模型（高召回）互补，低置信 span 回退词典；对标 99%

### 3.3 轻量替代模型（本仓库当前 Tier1）

字符 n-gram 哈希 + LogisticRegression，双语可用，本机 CPU 可训（10 万样本数分钟）。
作用：① 端到端链路验证与回归防护；② 为 0.6B 方案提供可复用的接口与评测基座。
0.6B ONNX 权重导出后经 `intent/qwen_head.py` 同接口接入，级联/服务/评测代码零改动。

## 4. 数据与评测体系（详见 docs/04）

| 数据集 | 规模 | 性质 | 用途 |
|---|---|---|---|
| 线上 query 银标注 | 100,438 | 规则弱标注 | Tier1/轻量模型训练、分布统计 |
| 合成金标评测集 | 572（中英双语，42 类全覆盖） | 模板合成金标 | 42 类覆盖性验证、回归防护 |
| 基线金标评测集 | 160（国内/海外各 80，产品 16 类） | 真实评测金标 | 真实分布水平度量、对齐业务目标 |

**指标口径与业务目标对齐**：产品 16 类 acc ↔ 统计层面 85%；L1 acc ↔ 排序层面 95%；标的/时间实体 F1 ↔ 99%。切片维度：语言 / 长度 / 含代码 / 含时间词 / 域。

## 5. 已识别风险与对策

| 风险 | 对策 |
|---|---|
| 规则银标注噪声传导到模型 | 高分样本(score≥2)优先；低分样本进难例池，LLM teacher + 人工抽检清洗 |
| 长尾类目 0 样本（SYSTEM/PREDICT 部分类） | 合成造数 + teacher 造数；搜索场景按需挂起（对齐 v2.1 挂起清单） |
| 事实核验类无专属落点（基线 160 条含此类） | 短期映射 INFO-04/07/08 并集；体系 v3 修订建议增补『事实核验』二级 |
| 情绪字段 0/1/2 历史债务 | canonical 别名层 + 双写，读侧强制走别名层（recall_linkage.json 已固化） |
| 0.6B 细粒度上限（L2 80–85%） | 级联拼接系统指标；escalation ladder：调门限→补 hard negative→升档 1.5B |

## 6. 实施路线（对齐试用期考核三阶段）

- **阶段一（1–2 月）**：本仓库全链路骨架 ✅ → 42 类标注规范评审 → teacher 考试与造数放量 → 标准评测集人工校验版
- **阶段二（3–4 月）**：0.6B 三头训练（服务器）+ NER 模型训练 → 离线评测对比 baseline（目标：相对提升 ≥10%，无系统性退化）→ 性能验证（P99/吞吐/显存）
- **阶段三（5–6 月）**：灰度上线（5%→25%→100%，规则/模型/级联三路开关）→ A/B 端到端验证 → Badcase 月度回流闭环 → 技术沉淀
